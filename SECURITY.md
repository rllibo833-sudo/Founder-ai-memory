# Security Policy

This repository is public. Treat every committed file as public information.

## Never commit

- Passwords
- OTPs
- API keys or access tokens
- Payment secrets
- KYC/identity documents
- Private credentials
- Private customer data
- Sensitive personal data not required for durable project memory

## Memory integrity

Use structured records and explicit statuses. Do not promote hypotheses or proposals to verified facts.

## Recovery integrity

A new chat must cross-check memory against the Central OS canonical status and active project contracts before treating a memory as current.

**No Proof, No Claim.**
